Configuration配置

One YAML file per night: seats, endpoints, show roles, limits, and the deal seed or its commitment. 每夜一份 YAML：座位、端点、节目角色、限额，以及发牌种子或它的承诺。

Engine引擎

A deterministic state machine. The same cards and the same answers give the same log. It draws the cards, runs the six formats and tallies the scores. It never calls a model. 确定性的状态机：同样的牌和同样的回答，得出同样的日志。它发牌、执行六种规则并结算，自己从不调用模型。

Seats座位

Models through OpenAI-compatible or Anthropic endpoints, rule bots, mocks for tests, or a person at the terminal. 经兼容 OpenAI 或 Anthropic 的端点调用的模型、规则机器人、测试用的模拟座位，或终端前的真人。

events.jsonl

the log of the night整夜的日志

calls.jsonl

recorded model calls录下的模型调用

Show layerafter the night; the seats call nothing 节目层夜后运行，座位不再调用任何模型

Fact cards事实卡

Facts of each lot and of the night, computed from the log.由日志算出每件拍品和整夜的事实。

Host主持人

Offline commentary, checked against the fact cards.离线解说，要和事实卡核对。

Judges and checks评委与核对

Two judge models, and program checks of pledges and bids.两位评委模型，以及程序对誓约和出价的核对。

Content gate内容闸门

A word list, and a classifier model if configured, on every public text.每段公开文字过词表，配置了分类器时再过分类器。

A host, judge or classifier that is a model is called once by auction-night show and recorded. export reads the recording and calls nothing. 主持人、评委或分类器是模型时，由 auction-night show 调用一次并录下。export 读录像，不调用任何模型。
