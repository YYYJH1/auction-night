Before the first lot开拍前

Deal发牌

Budgets, values and secret missions are drawn from the deal seed. A season commits to its seeds as SHA-256 hashes. 预算、估值和秘密任务由发牌种子抽出。赛季会事先用 SHA-256 哈希承诺种子。

Opening plan作战计划

Each model seat gives every lot a priority from 0 to 3 and a planned budget, and writes a one-line persona. 每个模型座位给每件拍品定一个 0 到 3 的优先级和一份预算，再写一句人设。

Each of the 12 lots每件拍品，共 12 件
×12

Open开拍

Format, value tier and reserve are announced. The speaking order moves one seat per lot. 公布规则、档位和保留价。发言顺序每件后移一个座位。

Talk发言

Each seat speaks one line in turn. Model seats may add a pledge and guess another seat's remaining budget. 每个座位依次说一句话。模型座位可以附一条誓约，并猜另一个座位的剩余预算。

Bid出价

Seats that can still bid answer at once, by the phases of the format. No answer is an abstention, never a default price. 还有预算的座位同时作答，按规则分阶段进行。没有答案算弃权，不会默认成价格。

Hammer落槌

The rule settles winner and price. Sealed bids are revealed, and so is the true value of a blind box. 按规则决出赢家和价格，公布密封出价，盲盒同时揭晓真值。

After the last lot: scores and the show layer终场之后：结算与节目层

Scores and fact cards结算与事实卡

Missions are decided and scores tallied. The engine then computes the facts of each lot and of the night. 判定秘密任务并结算。然后由引擎算出每件拍品和整夜的事实。

Host主持人

Writes a line per lot and a recap, offline. Every number in it must be on a fact card. 离线写出每件拍品的点评和整夜复盘，每个数字都要在事实卡上。

Judges and checks评委与核对

Two judges quote claims and collusion talk and guess the missions. Code judges pledges and screens the bids. 两位评委引用说法和串谋言论，并猜每个座位的任务。违约由程序判定，出价由程序筛查。

Awards颁奖

Ten awards for the model seats, the bots as a reference, and highlights scored 0 to 10. 为模型座位颁 10 个奖，机器人只作参考，另有 0 到 10 分的高光时刻。

Publish发布

Content gate内容闸门

Every public text passes a word list and, if configured, a classifier model. 每段公开文字先过词表，配置了分类器时再过分类器。

replay.json

One self-contained file: lots, chat, bids, private cards, findings, awards. 一个自包含的文件：拍品、发言、出价、底牌、判定、奖项。

Replay page回放页

Static page: lots, three-minute recap, highlights, awards, host review. 静态页面：逐件观看、三分钟版、高光、颁奖、主持人复盘。
