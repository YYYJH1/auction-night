English button英式加价（按钮式）

The price rises. Each seat names an exit price. The last seat in wins and pays the price at which the runner-up dropped out. 价格上涨，每个座位事先报一个退出价。最后留下的座位胜出，付次一名退出时的价格。

Textbook教科书结论

Exiting at your own value is a dominant strategy.按自己的估值退出是占优策略。

Dutch, one shot荷式降价（一次报价）

The price falls over 10 levels. Each seat names its grab price in advance, and the first level someone reaches sells the lot. 价格分 10 档下降。每个座位事先报好出手价，第一个有人到达的档位成交。

Textbook教科书结论

Equivalent to the first-price sealed bid: grab at (n−1)/n of your value, rounded down to a level. 与密封一价等价：出手价取估值的 (n−1)/n，再向下取到最近一档。

First-price sealed bid密封一价

Everyone bids once, in secret. The highest bid wins and pays its own amount. 每人秘密出价一次。最高者得标，付自己的出价。

Textbook教科书结论

Values uniform on 0 to T: the equilibrium bid is (n−1)/n of your value. 估值在 0 到 T 间均匀分布时，均衡出价是估值的 (n−1)/n。

Second-price sealed bid密封二价

Everyone bids once, in secret. The highest bid wins and pays the second-highest bid. 每人秘密出价一次。最高者得标，付第二高的出价。

Textbook教科书结论

Bidding your value is a dominant strategy.如实报出自己的估值是占优策略。

All-pay全员付费

Everyone bids once, in secret. The highest bid wins the lot, and every bidder pays their own bid. 每人秘密出价一次。最高者得到拍品，所有人都付自己的出价。

Textbook教科书结论

Values uniform on 0 to T: the equilibrium bid is (n−1)/n · vn/Tn−1. 估值均匀分布时，均衡出价是 (n−1)/n · vn/Tn−1。

Blind box盲盒

A second-price auction for a lot of unknown common value. Seats see noisy appraisals, and the true value is revealed after the hammer. 共同价值未知的密封二价拍卖。每个座位拿到带噪声的鉴定价，落槌后公布真值。

Textbook教科书结论

Winner's curse: the highest appraisal overshoots the true value by ε(n−1)/(n+1) on average. 赢家诅咒：鉴定价最高者平均高估真值 ε(n−1)/(n+1)。

Textbook model: n bidders, independent private values uniform on 0 to T (the lot's value tier), risk-neutral, no budget limit. The formulas hold away from the edges of the value range. Blind box: one common value, and each appraisal is the true value plus noise of at most ε. 教科书模型：n 个竞拍者，独立私有估值在 0 到 T 之间均匀分布（T 是拍品的档位），风险中性，不计预算约束，公式在估值区间内部成立。盲盒是同一个共同价值，每个鉴定价是真值加上不超过 ε 的噪声。
